# Retail-Sales-Analytics-Interactive-Dashboard-Development

Aim: Developed an ETL pipeline to extract, clean, validate and transform retail transaction data, enabling interactive analysis of sales, profitability, customer segmentation, discounting, returns and regional performance.

Results: Processed 4,310 raw records into 4,174 validated transactions (3.2% fewer records after cleaning); developed 3 interactive Tableau dashboards and identified key sales drivers, customer-value segments and category level profitability patterns. Analysed ₹232.34M in sales, ₹43.0M in profit and an 18.5% profit margin.
